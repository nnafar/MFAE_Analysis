For the batch analysis, name your data folders like the following:

Date_CellType_Treatment_ExperimentNumber-Pressure[Pa]-Voltage[V]-PulseDuration[ms|us|s]-Pulseframe

For cells that are eltroporated, the data folder name should be formatted as:

```
YYMMDD_MDAMB231_Control_Experiment271-1100Pa-100V-5ms-frame10
```

For cells that are just aspirated (no electrporation), the data folder name should be formatted as:

```
YYMMDD_MDAMB231_Control_Experiment271-1100Pa-0V-0ms-frame0
```
